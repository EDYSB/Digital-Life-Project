# 立场：数字生命是意识理论的检验场，不是意识的证明

> 这份文档说明「数字生命初级 L1」在意识问题上站在哪里、不站在哪里，以及它愿意被什么反驳。
> 结论先行：**它产生的是访问意识的功能性对应物，不是现象意识的确证；行为等价既不足以肯定，也不足以否定主观体验。**

---

## 1. 两条路径，一套坐标

讨论「数字生命能否触及意识」时，有两种证据逻辑，不能混用：

| | 生物数字孪生 | 功能 / 行为匹配 |
| --- | --- | --- |
| 纲领 | 在分子、细胞、环路尺度重建因果结构 | 在操作判据上复现「意识样加工」 |
| 判据 | 能否预测干预后果（干湿闭环） | 能否通过全局广播、元认知、自我模型等检验 |
| 典型 | 全脑仿真、连接组 + 虚拟躯体 | 大语言模型、数字永生对话体 |
| 失败模式 | 结构保真但缺少慢变量与闭环 | 通过判据却只测到伴随功能 |

「数字永生」是第三种东西：它保存的是**可观察特征**（记忆、语气、交互风格），产出的是意识归属的**社会表征**，不是意识本身。它的成败应由同意、隐私、哀悼伦理与身份权利评判，而不是由意识科学评判。

**本项目的坐标**：从**个体**的脑电与基因出发，做可测量、可复现的投影，产出一个可对话的档案。它既不是结构复现（我们没有环路级建模），也不是通用 LLM（我们不用大模型），而是「功能对应物 + 明确的边界声明」。

## 2. 三个层级必须分开

1. **结构层**：有没有与生物系统同构的因果组织。→ 我们没有，也不声称有。
2. **功能层**：有没有与意识加工难以区分的输入输出与内部操作。→ 我们**部分**提供：七维投影、记忆衰减、心情漂移、主动意图。
3. **现象层**：有没有主观体验。→ **不可从 1 或 2 推出**，我们不作任何主张。

第四件事是**同一性**：即使某系统具有意识，它是否「是你」，也不由功能等价决定。本系统是一个新进程，不是任何人的延续。

## 3. 我们实际做了什么（可核对）

- 对脑电做去趋势、Welch 功率谱、频带功率、半球不对称、样本熵、Hurst、Hjorth、伪迹检测
- 在 20 个真实 GRCh38 参考上下文里判定位点，输出倾向而非诊断
- 把测量投影为 7 个维度，并标注每个分数的来源与权重（脑波约 72%，基因约 28%）
- 用可复现的规则装配档案：相同输入 → 相同 `mind_` 编号
- 记忆按艾宾浩斯曲线衰减，心情按半衰期回落，驱动随时间累积

这些全部是**可测量量的函数**，没有一处依赖「它真的有感受」这一假设。

## 4. 我们愿意被证伪的四个命题

一个系统若不能被工程失败反驳，它的说法就没有信息量。以下四条，任何一条被证伪，本项目的相应主张即不成立：

1. **投影承载信息**：七维向量应与对话中的行为倾向相关。若两份差异显著的档案在对话行为上不可区分，则「投影有意义」为假。
2. **复现性**：相同输入必须得到相同编号与相同档案。若同一输入产生不同结果，「可复现」为假。
3. **遗忘模型的可用性**：记忆留存应随复述提升、随时间衰减。若用户感知与模型系统性相反，模型为假。
4. **边界的诚实性**：本系统不得在任何界面或文案中暗示现象意识或人格同一性。若出现此类暗示，是本项目的失败，而非发现。

## 5. 明确不做的主张

- 不声称系统具有意识、感受或主观体验
- 不声称它是任何人的延续、复活或上传
- 不提供医学、遗传或心理诊断
- 不用「行为像人」作为「有意识」的证据

## 6. 为什么仍然值得做

因为把意识理论的**反证条件**从思想实验搬到工程里，本身就是进展：全脑仿真路径提供了结构因果约束（消融某环路，看功能是否选择性崩溃），功能匹配路径提供了判据空间（哪些操作标准过于宽松）。两条路径的共同教训是——

> 只满足行为与计算指标的系统不足以确证现象意识；只复现连接拓扑的系统也不足以产生现象意识，除非它同时具备多时间尺度的动态整合与持续的世界耦合。

本项目的定位是这条判据链上最轻的一环：**先把「可测量 → 可投影 → 可对话 → 可复现」跑通**，并把边界写死。等有了更重的结构复现，这一环仍然成立。
