数字生命初级 · 命令行手册
Digital Life L1 · Command Reference
==================================================

说明
----
  dl 是 dl.cmd 的简称，等价于 python -m suoling.cli。
  在项目根目录下的 cmd 窗口里直接敲 dl 即可，不需要激活任何环境。
  所有命令都不联网（除非你填了 DeepSeek API key）。

--------------------------------------------------
一、总览
--------------------------------------------------

  dl                          显示帮助
  dl demo                     用内置样本跑一遍完整流程
  dl scan --eeg F --dna F     从两个文件生成档案
  dl create                   手工创造一个数字生命（仅命令行）
  dl list                     列出已保存的数字生命
  dl chat --id ID             与档案对话（逐行）
  dl tui  --id ID             在终端里开全屏界面
  dl final --id ID            最后一晚：写手记并自毁档案
  dl card --id ID             生成可打印的数字生命卡
  dl export --id ID           导出档案（md / json）
  dl stats --id ID            后台：查看全部参数
  dl brain --id ID            查看大脑激活
  dl brain-ui                 打开大脑可视化页面
  dl serve                    启动本地网页界面
  dl api [KEY]                查看或设置 API key
  dl account / login / logout 可选的多账户
  dl mode [gpu|web|auto]      运行模式

--------------------------------------------------
二、生成档案
--------------------------------------------------

dl demo
  用内置样本（samples/ 里的脑电 CSV 与基因 FASTA）跑完整条流水线，
  约 2 秒，生成一份档案并保存到 minds/。
  可选：--name 名字  --voice calm|warm|sharp|neutral  --no-save
        --json 输出.json  --markdown 输出.md

dl scan --eeg 脑电文件 --dna 基因文件 [--name 名字]
  用自己的数据生成档案。
  脑电支持：CSV / TSV / TXT / JSON / EDF / NPZ
  基因支持：FASTA / 23andMe / VCF / JSON
  相同输入 + 相同选项 = 相同编号，可复现。

dl list
  列出所有已保存档案：编号、mind id、创建时间、名字、标题。

--------------------------------------------------
三、对话
--------------------------------------------------

dl chat --id mind_xxxxxxxxxxxx
  逐行对话，输入 /quit 退出，/save 导出对话到 conversation.md。

dl tui [--id mind_xxxxxxxxxxxx]
  全屏终端界面：左边拟人像（半块字符渲染），右边对话，底部状态条。
  不带 --id 时自动取最新的一份。

dl final [--id mind_xxxxxxxxxxxx] [--yes]
  最后一晚。先念出它记得的事与对话，再说明最后一句，
  然后问 Y/N：
    Y → 写 out/final/<编号>-手记.md，备份原档案，删除 minds/<id>.mind
    N → 什么都不发生
  --yes 跳过确认（危险，脚本用）。

--------------------------------------------------
四、导出
--------------------------------------------------

dl card --id ID [--out 文件] [--no-open]
  生成一张 HTML 生命卡，默认写到 out/<编号>-card.html 并自动打开浏览器。

dl export --id ID [--format md|json]
  md   → 可读的 Markdown 档案
  json → 完整的 .mind 内容

--------------------------------------------------
五、后台与大脑
--------------------------------------------------

dl stats [--id ID]
  唯一显示参数的地方：编号、导联数、采样率、质量、位点、置信度、
  来源文件、会话/消息数、记忆条数、心情、七维分值。

dl brain [--id ID] [--poke 一句话]
  显示五个区域（感知 / 记忆 / 情绪 / 语言 / 自我）的激活强度与拍数。
  --poke 给一句话，让它想一拍，然后打印这句话点亮的念头。

dl brain-ui
  打开 http://127.0.0.1:8017/brain.html
  独立页面，不随网页自动启动。本地服务没起会自动拉起。

--------------------------------------------------
六、网页界面
--------------------------------------------------

dl serve [--port 8017] [--no-browser]
  启动本地服务器，默认 http://127.0.0.1:8017
  首页是对话框：立绘、问候语、输入框；点她会弹表情包，她会自己随机做动作。
  ?classic=1 进入原来的录入页（数据上传、样本选择、融合动画）。

--------------------------------------------------
七、API key
--------------------------------------------------

dl api
  查看当前 key（打码显示）、模型名、端点。

dl api sk-xxxxxxxxxxxx
  写入 config.json，立即生效（网页与命令行都会用）。

dl api --clear
  清空 key，回到纯本地规则，不联网。

  也可以改环境变量 DEEPSEEK_API_KEY 覆盖。
  没填 key 时行为与未接入时完全一致。

--------------------------------------------------
八、账户（可选）
--------------------------------------------------

不建账户时：所有档案在 minds/ 下，本机任何人都能看。

dl account [--user 名字]
  建账户并自动登录。之后的档案放在 minds/<账户>/，互相不覆盖。
  口令用 PBKDF2-HMAC-SHA256 + 随机盐，存在 minds/.users.json。

dl account --off
  取消整个账户体系，回到公共目录。

dl login [--user 名字]
dl logout
dl whoami
  切换 / 退出 / 查看当前身份与档案目录。

  注意：它挡的是误看与误删，挡不住能读你磁盘的人。

--------------------------------------------------
九、模式
--------------------------------------------------

dl mode
  查看当前模式。

dl mode gpu | web | auto
  gpu  — 接 VoxEMW / LiveTalking 这类后端（config.json 的 voice_backend）
  web  — 浏览器里的立绘与动作（默认）
  auto — 有 voice_backend 就用 gpu，否则 web

--------------------------------------------------
十一、常见问题
--------------------------------------------------

Q: 敲 dl 提示"不是内部或外部命令"？
A: 你不在项目根目录。先 cd 到 "D:\EDY_POWERQ\Digital Life Project"。

Q: dl cmd 出现乱码？
A: dl.cmd 是纯 ASCII + CRLF，中文全部由 Python 输出。
   不要用会把 .cmd 存成 UTF-8 BOM 的编辑器重新保存。

Q: 想改回原来的录入页？
A: 浏览器打开 http://127.0.0.1:8017/?classic=1

Q: 自毁时提示服务还在运行？
A: 先关掉 dl serve 的窗口或 Ctrl+C，否则它会把档案写回去。

Q: 没有 GPU 能用吗？
A: 能。网页端的立绘与动作不需要 GPU；只有接数字人后端时才需要。

dl create [--name 名字] [--voice calm|warm|sharp|neutral] [--traits 好奇=70,共情=80]
  手工创造一个数字生命：不传脑电与基因，七维数值自己定，0-100。
  同样参数 = 同样编号，可复现。只支持命令行，网页不能创建。
